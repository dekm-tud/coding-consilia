Query-encoder parity

Embeds the 50 fixed queries in tools/parity_queries.json with the model exactly as the search page ships it (transformers.js, same worker, same dtype/device choice) and compares them with the fp32 reference vectors from python tools/parity_ref.py ref --tag <tag>. Requirement: mean cosine ≥ 0.98 and mean top-20 overlap ≥ 0.9 against the corpus vectors. Serve the repository root (python -m http.server) and open /tools/parity_check.html?model=etp-bgem3-ft (add &auto=1 to start immediately; this downloads the model).
